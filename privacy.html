Privacy Policy

Last updated: November 22, 2026

Hermes Google Workspace is a personal tool for one user. It is not offered to the public.

What the app accesses

With the user's explicit consent through Google's OAuth flow, the app accesses the user's Gmail, Google Calendar, Google Drive, Google Sheets, Google Docs, and Google Contacts. It does so only to carry out actions the user requests.

Where data is stored

OAuth tokens are stored locally on the user's own computer. The app does not operate a server that collects or stores user data.

Sharing

No data is sold, rented, or shared with third parties. Data is sent only to Google's APIs as needed to fulfill the user's requests.

Revoking access

The user can revoke access at any time at myaccount.google.com/permissions, or by running the app's revoke command.

Contact

Questions: open an issue at github.com/Cyacuk/hermes-google-workspace-site.
